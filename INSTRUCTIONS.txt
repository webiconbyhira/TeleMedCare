====================================================
  STEP 1 — XAMPP INSTALL KAREIN (agar nahi hai)
====================================================

1. Browser mein jao: https://www.apachefriends.org
2. "Download" button dabao — Windows version download hoga
3. Download hone ke baad .exe file run karein
4. Installation wizard mein bas "Next" dabate jao
5. Default folder C:\xampp\ pe install hone do
6. Install ho jane ke baad "Finish" karein

====================================================
  STEP 2 — XAMPP START KAREIN
====================================================

1. Desktop pe "XAMPP Control Panel" icon dhundo
   (ya Start menu mein search karein "XAMPP")
2. XAMPP Control Panel khulega
3. "Apache" ke saamne "Start" button dabao → Green ho jaye ga
4. "MySQL" ke saamne "Start" button dabao → Green ho jaye ga
5. Dono green ho jayen to XAMPP ready hai ✅

====================================================
  STEP 3 — WEBSITE FOLDER BANAO
====================================================

1. File Explorer kholo
2. Address bar mein type karein:
   C:\xampp\htdocs
   (Enter dabao)
3. Wahan right click karein → "New" → "Folder"
4. Naam rakho: telecare
5. Ab saari files us folder mein copy karein:
   C:\xampp\htdocs\telecare\
   (index.html, doctors.html, booking.html, login.html,
    style.css, book_appointment.php, auth.php,
    chatbot.php, database.sql — sab yahan aayenge)

====================================================
  STEP 4 — DATABASE BANAO
====================================================

1. Browser mein jao:
   http://localhost/phpmyadmin

2. Upar menu mein "SQL" tab click karein

3. "database.sql" file ko Notepad mein kholo
   (Right click → Open with → Notepad)

4. Notepad se poora text select karein (Ctrl+A)
   aur copy karein (Ctrl+C)

5. phpMyAdmin ke SQL box mein paste karein (Ctrl+V)

6. Neecha "Go" button dabao

7. "telecare_db" database ban jayega with tables ✅

====================================================
  STEP 5 — WEBSITE KHOLO
====================================================

Browser mein type karein:
   http://localhost/telecare/index.html

WEBSITE CHAL JAYEGI! 🎉

====================================================
  STEP 6 — AI CHATBOT SETUP (Optional)
====================================================

Chatbot ke liye Claude AI API key chahiye hoti hai.

1. Jao: https://console.anthropic.com
2. Account banao (free hai sign up)
3. "API Keys" section mein "Create Key" karein
4. Key copy karein

5. "chatbot.php" file Notepad mein kholo
6. Yeh line dhundo:
   $api_key = "YOUR_ANTHROPIC_API_KEY_HERE";
7. YOUR_ANTHROPIC_API_KEY_HERE ki jagah apni key paste karein
8. File save karein

====================================================
  COMMON PROBLEMS & SOLUTIONS
====================================================

Problem: Page nahi khul raha
Solution: XAMPP mein Apache green hai? Check karein

Problem: "Database connection failed"
Solution:
- MySQL start hai XAMPP mein?
- database.sql run kiya phpMyAdmin mein?

Problem: Chatbot jawab nahi de raha
Solution:
- chatbot.php mein API key daali hai?
- API key sahi hai console.anthropic.com se?

Problem: Booking save nahi ho rahi
Solution:
- MySQL running hai?
- appointments table bana hai? (database.sql chalaein)

====================================================
  DATABASE MEIN DATA KAISE DEKHEIN?
====================================================

1. http://localhost/phpmyadmin jao
2. Left side mein "telecare_db" click karein
3. "appointments" table click karein
4. "Browse" tab — sab bookings dikhengi
